### Frontmatter 日期损坏问题

**严重度: P1**

56 篇文章的前置元数据日期字段带有尾部垃圾字符（如 `2023-03-09T12:57:23+08:00"` 带有多余的 `"` 和换行符），导致 `z.coerce.date()` 无法解析。所有 Hugo 迁移来的旧文章受影响。

**批量修复命令**（使用 PowerShell）:
```powershell
Get-ChildItem "src/content/blog" -Recurse -Filter "*.md" | ForEach-Object {
    $content = Get-Content $_.FullName -Raw -Encoding UTF8
    $content = $content -replace '(date:\s*\S+)\s*["'']*\s*$', '$1'
    $content -replace "`r`n", "`n" | Set-Content $_.FullName -Encoding UTF8 -NoNewline
}
```

**警告**: 请先在几个文件上测试，确保不会破坏内容。
