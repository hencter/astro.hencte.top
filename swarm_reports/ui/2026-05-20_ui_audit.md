## 第四部分: 响应式设计

### 4.1 断点矩阵

| 文件 | 断点 | 策略 |
|------|------|------|
| `global.css` | `max-width: 920px`, `max-width: 640px` | 2 级渐进 |
| `FullscreenAncientLayout.astro` | `max-width: 720px` | 单断点 |
| `NovelLayout.astro` | `max-width: 768px` (mobile), `min-width: 769px` (desktop) | 移动优先 + 桌面覆盖 |
| `WechatWidget.astro` | `max-width: 640px` | 单断点 |

**问题**:
1. 断点不一致: 640px / 720px / 768px / 920px — 缺少统一断点 token
2. **零 Tailwind 响应式类** (`sm:` / `md:` / `lg:` / `xl:`) — 项目安装 Tailwind CSS v4 但完全未使用其响应式系统
3. `NovelLayout` 的 `min-width: 769px` `@media` 块有**语法错误** (line 262-287): 一个多余的闭合花括号导致多个规则在该 scope 外重复定义

### 4.2 响应式策略评估

| 技术 | 使用量 | 评价 |
|------|--------|------|
| `clamp()` 流体值 | 大量 (padding, font-size, width) | 🟢 优秀 |
| CSS Grid `1fr` 坍塌 | 多处 (card-grid, blog-list-grid, about-split) | 🟢 自动崩塌到单列 |
| `flex-wrap` | header (site-header) | 🟢 导航自动换行 |
| `overlay` 滚动条 | FullscreenAncientLayout | 🟢 Gutters stable |

### 4.3 NovelLayout 的 CSS 语法错误

`NovelLayout.astro:262-287` 存在结构问题:

```css
@media (min-width: 769px) {
  body { ... }
  .nv-top-bar { ... }  /* line 268-272 */
  .nv-content { ... }  /* line 273-277 */
  .nv-prose { ... }    /* line 278 */
  .nv-bottom-bar { ... } /* line 279 */
}
  .nv-content { ... }  /* ⚠️ line 281-285: 在 @media 闭合花括号外 */
  .nv-prose { ... }    /* ⚠️ line 286: 同上 */
  .nv-bottom-bar { ... } /* ⚠️ line 287: 同上 */
}                       /* ⚠️ line 288: 多余的闭合花括号 */
```

这些额外规则在 `@media` 块外侧, 但被多余 `}` 隔离, **导致整个文件 `</style>` 后面的 `</head>` 可能被解析异常**。

## 第六部分: 技术债务与建议

### 🔴 严重

1. **NovelLayout CSS 语法错误** (`NovelLayout.astro:288`) — 多余的 `}` 花括号可能导致渲染异常
2. **WCAG 1.4.4**: `user-scalable=no` — 移除 `maximum-scale` 和 `user-scalable`
3. **WCAG 2.4.7**: `.theme-toggle` 缺少 `:focus-visible`

### 🟡 中等

4. **DRY 违规**: 5 个文件各自定义 CSS token 集 — 建议统一到 `global.css` 或共享 design-tokens.css
5. **WechatWidget 重复**: `WechatWidget.astro` 与 `NovelLayout` 内联 `.nv-wechat-widget` 功能重复
6. **`formatDate()` 重复**: 同一函数出现在 BaseLayout, BlogSectionLayout, blog/index.astro — 提取到 `src/lib/date.ts`
7. **缺少 skip-to-content 链接** (WCAG 2.4.1)
8. **`Welcome.astro` 废弃组件** — 残留 `text-rose-500` 类 (非项目色)
9. **`<meta name="color-scheme">` 缺失** — BaseLayout 未声明 `color-scheme`

### 🟢 低

10. **缺少 `::selection` 样式** — 可添加品牌色选中
11. **断点不统一** — 建议定义 `--bp-sm` / `--bp-md` / `--bp-lg` CSS 变量或全局 Tailwind breakpoints
12. **零 Tailwind 响应式类使用** — Tailwind v4 已安装但完全未利用
13. **NovelLayout 复制/粘贴/右键全部禁用** — 版权保护可用, 但对辅助技术用户不友好; 建议用 CSS `::after` watermark + 服务端检测替代 JS 拦截
14. **无 `prefers-color-scheme` CSS 回退** — 完全依赖 JS; 建议在 `:root` 添加 `@media (prefers-color-scheme: dark)` 作为 CSS 回退
