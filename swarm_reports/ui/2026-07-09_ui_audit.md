## 组件库评估

| 方案 | 框架依赖 | 优势 | 劣势 | 推荐度 |
|------|---------|------|------|--------|
| **纯 Astro 组件** | 无 | 零 JS bundle、SSG 友好、与现有架构一致 | 无复杂交互组件 | ⭐⭐⭐⭐⭐ |
| **Web Components (Lit)** | 无 | 框架无关、可在 Astro 中直接使用 | 生态较小、SSR 需额外处理 | ⭐⭐⭐ |
| **shadcn/ui** | React | 组件丰富、a11y 内置 | 引入 React 运行时 (~40KB+)、开发体验下降 | ⭐⭐ |
| **Alpine.js** | Alpine.js (~15KB) | 轻量、无需构建、适合交互增强 | 仅限简单交互 | ⭐⭐⭐ |

**结论**: 推荐**纯 Astro 组件**路线。当前站点交互需求极低（仅 theme toggle、scroll reveal、微信弹窗），不需要引入任何框架。Phase 1-2 的组件提取即可覆盖所有需求。
