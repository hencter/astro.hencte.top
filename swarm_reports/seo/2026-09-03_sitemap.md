## 结论

`@astrojs/sitemap` 早已接入，但 **i18n.locales 键用了 BCP-47（`en-US`/`zh-TW`/`zh-HK`）而非 URL 路径段（`en`/`tw`/`hk`）**，导致 hreflang alternate 无法正确配对路径。本轮修正 keys，并补齐 `filter`（404 + `/novel` 重定向别名）。

**Follow-up（同日）**：初版误把 `/shelf` 与 `/novel` 一并排除。书架是主内容路径，**必须进入 sitemap**；仅排除 404 与 legacy `/novel` redirect aliases。

## 配置摘要

```js
// astro.config.mjs — integrations
sitemap({
  i18n: {
    defaultLocale: "zh-CN",
    locales: {
      "zh-CN": "zh-CN", // no prefix → /
      en: "en-US",      // /en
      tw: "zh-TW",      // /tw
      hk: "zh-HK",      // /hk
    },
  },
  filter(page) {
    if (/\/404\/?$/.test(new URL(page).pathname)) return false;
    if (page.includes("/novel")) return false; // aliases only; /shelf allowed
    return true;
  },
  serialize(item) {
    if (/\/404\/?$/.test(new URL(item.url).pathname)) return undefined;
    if (item.url.includes("/novel")) return undefined;
    return item;
  },
})
```
