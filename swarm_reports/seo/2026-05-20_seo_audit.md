## 4. i18n 与 hreflang

### 当前状态
- **i18n 路由已配置** (`astro.config.mjs:13-27`)：zh-CN (`/`) + en-US (`/en`)
- **语言切换链接存在**：BaseLayout header 中的 `/` ↔ `/en` 切换（`src/layouts/BaseLayout.astro:32`）
- **hreflang 标签**：❌ 完全缺失
- **canonical 标签**：有但未在 zh/en 间关联

### 示例：首页 zh → en 关系
```
/ (zh-CN) 应在 head 中包含：
  <link rel="alternate" hreflang="en-US" href="https://hencte.top/en" />
  <link rel="alternate" hreflang="zh-CN" href="https://hencte.top/" />
  <link rel="alternate" hreflang="x-default" href="https://hencte.top/" />

/en (en-US) 应在 head 中包含：
  <link rel="alternate" hreflang="en-US" href="https://hencte.top/en" />
  <link rel="alternate" hreflang="zh-CN" href="https://hencte.top/" />
  <link rel="alternate" hreflang="x-default" href="https://hencte.top/" />
```

## 7. 优先修复建议 (Top 5)

### 1. 添加 `site` URL + 安装 `@astrojs/sitemap`
**影响**：当前构建生成的 URL 不完整，无 sitemap 导致搜索引擎无法发现页面。
**操作**：
```bash
pnpm add @astrojs/sitemap
```
在 `astro.config.mjs` 中添加 `site: "https://hencte.top"` 和 sitemap integration。

### 2. 创建 `public/robots.txt`
**影响**：无抓取指引，且用户的 AI 爬虫拦截意图未生效。
**内容建议**：
```
User-agent: *
Allow: /
Sitemap: https://hencte.top/sitemap-index.xml

User-agent: GPTBot
User-agent: anthropic-ai
User-agent: Google-Extended
Disallow: /novel/

User-agent: *
Disallow: /novel/
```

### 3. 实现 hreflang 标签
**影响**：当前中英文页面可能被搜索引擎视为重复内容，i18n 投入的 SEO 价值无法兑现。
**位置**：`src/components/Meta.astro` 增加 `alternateLocales` prop 或 `BaseLayout.astro` 中动态生成。

### 4. 安装 `@astrojs/rss` 并创建 RSS feed
**影响**：用户无法订阅更新，减少回访。
**操作**：
```bash
pnpm add @astrojs/rss
```
创建 `src/pages/rss.xml.ts`。

### 5. 修复 NovelLayout 和 FullscreenAncientLayout 的 SEO 缺口
**影响**：小说章节和古文内容对搜索引擎完全不可见。
**操作**：
- NovelLayout: 引入 Meta 组件，添加 canonical、OG 标签、Article/BreadcrumbList JsonLD
- FullscreenAncientLayout: 同样添加基础 SEO 标记
