## URL 策略

采用与现有 `/en` 一致的短路径前缀：

| Locale | hreflang | URL 前缀 | 示例 |
|--------|----------|----------|------|
| zh-CN (默认) | `zh-CN` | `/` | `/`, `/about`, `/projects` |
| zh-TW | `zh-TW` | `/tw` | `/tw`, `/tw/about`, `/tw/projects` |
| zh-HK | `zh-HK` | `/hk` | `/hk`, `/hk/about`, `/hk/projects` |
| en-US | `en-US` | `/en` | `/en`, `/en/about`, `/en/projects` |

**选择理由**: 与 `/en` 模式一致，URL 简短易记；Astro i18n 配置中使用 locale code (`zh-TW`/`zh-HK`) 与 path (`/tw`/`/hk`) 分离，SEO hreflang 使用标准 BCP 47 语言标签。

## 内容镜像策略

- **构建时转换**: 使用 `opencc-js` 从 `src/content/zh/` 简体 connect 内容自动生成繁体版本
- **转换模式**: `s2tw` (台湾) / `s2hk` (香港)
- **品牌词保护**: 亦幸、Hencter、Nova、Obsidian、LinkTrust、通天路等专有名词不参与转换
- **内部链接重写**: `/projects` → `/tw/projects` 或 `/hk/projects`；博客 `/blog`、`/log` 等保持共享路径
